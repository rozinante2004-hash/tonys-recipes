💬 WhatsApp Groups

WhatsApp has no API for reading groups, and tools that automate WhatsApp Web breach its terms and get numbers banned. The supported route is WhatsApp's own Export chat → Without media, which gives you a .txt file.

🔄 Synced chats — start here

Chats stored alongside your recipes, in the same cloud and behind the same sign-in. This is the option that works on every device, including a work phone that blocks GitHub, because nothing here touches the repo. Import below and it appears everywhere you are signed in.

📂 Import an export

Reads the file straight from this device — on the iPhone: Save to Files first, then pick it here (the full steps are at the bottom of this panel). With the box below ticked it is also synced to your other devices; untick it and the chat stays in this browser and nowhere else.

☁️ Shared folder — needs GitHub

The older route: .txt files committed to the repo's whatsapp/ folder. Still read, and still fine from a computer. It cannot work on a device that blocks GitHub — reading and uploading both go through the same API — so prefer Synced above unless you have a reason not to.

Loaded chats
How to export, and how to keep it up to date
Exporting (both platforms): open the group → group name → Export chat → Without media.

From an iPhone, step by step — this is the whole route, and it needs no GitHub access at all:
1. WhatsApp → open the group → tap the group name at the top → scroll down → Export Chat → Without Media.
2. WhatsApp prepares the file (a few seconds on a big group), then the Share sheet opens.
3. Scroll the lower list of actions and tap Save to Files. Pick somewhere you will find again — On My iPhone → Downloads is fine — then Save.
4. Come back here: 📂 Import exported .txt or .zip files above.
5. The iPhone's file picker opens. The export is usually the top entry under Recents; otherwise tap Browse and go to where you saved it. Tap it.

Worth knowing: WhatsApp hands you a .zip named _chat.zip or similar, not a .txt — that is correct, and this app opens it itself. Do not unzip it on the phone. And leave Also sync imported chats ticked, or the chat stays on the phone and never reaches your other devices.

Keeping it current — how far automation actually goes:
• The export itself must be started by hand. WhatsApp offers no scheduled or programmatic export, on any platform.
• iPhone: the delivery afterwards can be automated if the device can reach GitHub — a Shortcut that accepts a file from the Share sheet and uploads it via the GitHub API. On a work-managed phone that blocks GitHub, the five steps above are the route, and they do not depend on it.
• Android/desktop: share or copy the file into the repo folder and commit it; a sync-folder script can do the commit for you.
• Re-exporting produces the whole history again, so replacing the old file is the right move — that's why loading the folder replaces its entries rather than appending.

🔖 Bring! Token Bookmarklet

This bookmarklet refreshes your Bring! connection in one click. Set it up once, use it whenever needed.

Step 0: the shared secret

Must match BRING_SETTOKEN_SECRET on the Cloudflare Worker. It is stored on this device only and never committed — the old value was hard-coded in the public repo, which made it no secret at all.

Step 1: Copy the bookmarklet code
Step 2: Create a bookmark

In Chrome: Bookmarks menu → Add page → paste the code as the URL.
Name it "Refresh Bring! Token".

Step 3: Use it

When your Bring! token expires, go to web.getbring.com (while logged in) and click the bookmark. Done!

No bookmarks bar visible? Press Ctrl+Shift+B. Sized popup windows never show one — that's why this app now opens Bring! as a normal tab.

No bookmark? Paste the token instead

On web.getbring.com press F12 → Console, run copy(localStorage.accessToken), then paste it here.
