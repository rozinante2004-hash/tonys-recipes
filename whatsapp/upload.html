Upload a chat export

Puts a WhatsApp export straight into the app's whatsapp/ folder — no laptop.
This repository is public, so anything uploaded here is public too. That is already true of the laptop route — but worth knowing before uploading a family group.
Fine-grained token, this repository only, Contents: Read and write. Create one. Stored on this device only, so you paste it once.
WhatsApp gives you a .zip containing _chat.txt. Upload it exactly as it is — the app unpacks it itself.
Keep it plain ASCII. Upload a later export under the same name to replace it — re-exporting gives you the whole history again, not just the new part.
Then in the app: ⚙️ Settings → 💬 WhatsApp Groups → Load chats from this folder.
To see what is already there: list the folder.
